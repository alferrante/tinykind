# Email security operations

All provider sends use `src/lib/email.ts`: a persisted logical-event lease, payload-bound idempotency key, and suppression check before every retry. Do not call Resend directly from routes. A sent event stays sent; an ambiguous event older than 23 hours is held for delivery review instead of automatically resending after Resend's 24-hour idempotency window. Do not clear delivery records to force retries.

Complaint and permanent-bounce events enter `/api/webhooks/resend`. Set `RESEND_WEBHOOK_SECRET` from that endpoint's Resend signing secret. Subscribe to `email.complained` and `email.bounced`; permanent bounces suppress, transient bounces do not. Raw-body signature/timestamp verification precedes parsing and mutation. Events from other sending addresses are ignored. Suppression is durable, covers all app email types, and normalizes Gmail aliases. There is no public unsuppression endpoint. Restoring old backups must preserve current suppression and delivery ledgers.

Login bot protection uses a Cloudflare Turnstile managed widget restricted to the app hostname. Set `TURNSTILE_SITE_KEY` and private `TURNSTILE_SECRET_KEY`, then `TURNSTILE_ENABLED=1`. The site key is intentionally exposed to the login page; the secret is server-only. Tokens are checked server-side against the canonical `NEXT_PUBLIC_BASE_URL` hostname and action `auth-login`, before reserving sending quota. Verification outages fail closed while Google sign-in remains available. Missing keys never grant access when protection is enabled. An unset/disabled configuration preserves the existing quota-protected email flow; it must not be represented as active bot protection.

Test with `npm run test:security`, `npm run build`, and `npm run lint`. Test provider calls are mocked; do not run abuse or load tests against production. Live activation requires real account configuration and verification of the widget and delivery-event endpoint. Provider secrets belong only in the deployment's environment, never in source or reports.
